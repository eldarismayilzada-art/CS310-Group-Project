## The Problem

Currently, Sabancı University lacks a unified platform where all student clubs can communicate with students.  We are integrating all the clubs together in one app to allow students to communicate with the clubs faster and more efficiently.

## Core Features

- Filtering of the clubs based on students interests and making suggestions. 
- Posts can be made by clubs including posters, images, videos and text.
- Board members will be able to post announcements from their account. 
- Clubs will be able to notify students and inform them about events with a 24 hour story.
- A calendar section will be created where all the events will be posted and reminders would be sent for the students. 
- Calendars will be created based on the students preferences to not overload them. 
- Comments can be applied to posts and announcements. 

## Nice-to-Have Features

- Advanced recommendation algorithms
- Event registration system
- University system integration


## Main Purpose

The main purpose of ClubHub is to create a centralized and user-friendly environment where students can easily access all club-related information and engage with clubs more effectively.

## Target Audience

Sabancı University students and university clubs

## Platform

The application will be developed using Flutter for both iOS and Android platforms.

## Data Storage

- User Data (name, email, role, and preferences) 
- Club Data (club information, descriptions, and categories) 
- Event Data (event details, date, location, and capacity) 
- Membership Status Data (which users belong to which clubs) 
- Announcement and Post Data (posts, media content, and comments) 


## Unique Selling Point

It creates a platform where everything is in one place and students can learn about announcements, sign up for events and discover clubs without the need for multiple platforms.

## Challenges

- Ensuring data privacy and security 
- User-friendly interface 
- Managing communication between the clubs and students
